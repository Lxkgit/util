Windows 客户端打包

推荐环境：
- Windows 10/11 x64
- Python 3.11 x64
- 无需安装 VLC，打包脚本会下载官方 VLC 便携 ZIP 运行库

自动打包：
1. 在 PowerShell 中进入 client 目录。
2. 执行：
   powershell -ExecutionPolicy Bypass -File .\build.ps1
3. 首次执行会创建 .venv，自动安装 requirements.txt 中缺少的依赖。
4. 自动从 VideoLAN 官方站点下载 VLC 便携 ZIP 包，并校验 SHA256。
5. 自动解压 VLC 运行库、检查依赖并执行 PyInstaller。
6. VLC 压缩包和解压文件缓存在 .build-cache\vlc-3.0.24，后续打包会复用，不需要重复下载。

打包结果：
dist\main\main.exe

注意：
- 不需要在打包电脑上安装 VLC，也不会调用 winget。
- 必须复制整个 dist\main 文件夹，不能只复制 main.exe。
- VLC 的 libvlc.dll、libvlccore.dll 和 plugins 会一并打包。
- 当前打包方式为 onedir，不是单文件 exe。
- aiortc / PyAV 包含原生二进制依赖，仍需在未安装 Python 的 Windows 10/11 测试机上验证。
- VLC 官方下载目录：https://download.videolan.org/pub/videolan/vlc/last/win64/
