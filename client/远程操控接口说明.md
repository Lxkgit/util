# 远程操控接口约定（第一阶段）

服务端地址：`http://124.221.195.130`

## 设备注册

- 方法：POST
- 路径：`/api/file/client/register`
- Content-Type：application/json
- JSON 必须包含 `key`。
- 客户端提交完整设备 JSON；服务端按设备 key 保存。

当前客户端注册字段：

```json
{
  "key": "客户端本地生成并持久化的唯一标识",
  "deviceName": "Windows 主机名",
  "platform": "Windows 版本信息",
  "version": "1.0.0",
  "signals": []
}
```

## 心跳

- 方法：GET
- 路径：`/api/file/client/heartBeat?key={key}`
- 客户端每 60 秒发送一次。
- 服务端 Redis TTL 为 300 秒。
- 关闭“允许本机被发现”后，客户端停止心跳；服务端记录等待 TTL 自然过期。

## 在线设备列表

- 方法：GET
- 路径：`/api/file/client/list`
- 客户端每 5 秒轮询。
- 响应的 `result` 是 JSON 字符串数组，客户端逐条反序列化。

## 重要约束

1. 设备标识字段使用 `key`，不是 `deviceKey`。
2. 心跳只刷新 TTL，不更新设备 JSON。
3. 当前阶段尚未写入 WebRTC 信令，也没有开放远程业务请求。
4. 注册接口应只允许设备所有者更新对应设备记录；目前接口若无身份认证，不能把公开的 key 当作访问授权凭证。
